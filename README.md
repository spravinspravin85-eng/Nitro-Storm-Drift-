🌐 Play Online

NSD is designed to run through a web browser.

After enabling GitHub Pages, your game will be available at:

https://YOUR-USERNAME.github.io/NSD-NITRO-STORM-DRIFT/

Replace "YOUR-USERNAME" with your GitHub username.

🚀 Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Start a local web server.

Using Python:

python -m http.server 8000

4. Open this address in your browser:

http://localhost:8000

Do not open "index.html" directly using "file://"; JavaScript modules require a web server.

📱 Android Installation

1. Publish the project using GitHub Pages.
2. Open the published game in Chrome.
3. Use Chrome's menu to select Add to Home screen, if available.
4. Launch NSD from the home screen.
